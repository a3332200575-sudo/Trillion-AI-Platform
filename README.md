# Trillion-AI Platform

A responsive landing page exploring business opportunities in AI agents, integration automation, and connected operations.

## Features

- Responsive layout for desktop, tablet, and mobile
- Sections covering the market thesis, opportunity areas, and an automation playbook
- Mobile navigation menu
- No framework, package installation, or build step required

## Project files

- `index.html` — page structure and content
- `styles.css` — styling and responsive layouts
- `script.js` — mobile navigation and footer year

## Run locally

Open `index.html` in a browser.

Alternatively, serve the repository with any static file server. For example, with Python:

```bash
python -m http.server 8000
